# CV Website – Sinh viên Sư phạm Khoa học Tự nhiên

## Cách dùng
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome/Edge.
3. Nhấn đúp vào tên trên đầu CV để bật chế độ chỉnh sửa.
4. Khi chỉnh sửa, các ô nội dung có nền vàng nhạt là ô có thể sửa trực tiếp.
5. Nút **Lưu thay đổi** lưu nội dung trên trình duyệt bằng localStorage.
6. Nút **Đổi ảnh** cho phép thay ảnh cá nhân.
7. Hai thí nghiệm là mô phỏng PhET chạy online; nếu trình duyệt không cho nhúng iframe, bấm **Mở thí nghiệm** để mở trực tiếp.

## Đưa website lên mạng
Có thể tải nguyên thư mục này lên GitHub Pages, Netlify hoặc Vercel. Không cần backend.
